== Description ==
Modern, high-performance WordPress theme for AVR Web Consulting - Digital Marketing, AI SEO, GEO, AEO, LLMO, and Web Development agency.

== Installation ==
1. In your WordPress admin, go to Appearance > Themes.
2. Click "Add New Theme" and then click "Upload Theme".
3. Choose the "avr-web-consulting.zip" file and click "Install Now".
4. After installation, click "Activate".
5. Customize your company phone, email, WhatsApp, and office address under Appearance > Customize > AVR Company Information.

== Structure ==
- style.css: Theme definition and core CSS variables
- functions.php: Script enqueuing, customizer options, theme setup
- index.php: Main blog and search index fallback
- front-page.php: Agency homepage with video hero, AI SEO highlights, and services
- header.php: Responsive header with accessible navigation and mobile drawer
- footer.php: Agency footer with contact details, quick links, and WhatsApp CTA
- assets/css/main.css: Production Tailwind CSS stylesheet
- assets/js/theme.js: Vanilla JavaScript for mobile drawer, table overflow, and accordions
