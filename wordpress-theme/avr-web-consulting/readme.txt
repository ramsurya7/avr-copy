== Description ==
Modern, high-performance, fully editable WordPress theme for AVR Web Consulting - Digital Marketing, AI SEO, GEO, AEO, LLMO, and Web Development agency.

== Installation ==
1. In your WordPress admin, navigate to Appearance > Themes.
2. Click "Add New Theme" and then click "Upload Theme".
3. Choose the "avr-web-consulting.zip" file and click "Install Now".
4. After installation finishes, click "Activate".
5. Live editing: Go to Appearance > Customize > AVR Theme Customizer to adjust Hero headlines, CTAs, phone, email, WhatsApp, and stats counters.

== Page Templates Included ==
- Front Page (front-page.php): Full agency homepage with video background hero, service cards, and stat highlights.
- Service Showcase (template-service.php): Quick answer block, deliverables table, and collapsible FAQ accordion.
- Contact & Audit Request (template-contact.php): Interactive AJAX contact form, office channels, and WhatsApp trigger.
- Pricing & Plans (template-pricing.php): 3-tier pricing cards with feature comparisons and direct consultation CTAs.
- Interactive FAQs (template-faqs.php): Categorized collapsible FAQ accordions for SEO and Web Development.
- Full Width Page (template-fullwidth.php): Container-wide layout without sidebars, ideal for custom Gutenberg and page builders.
- Main Blog & Archives (index.php): Clean grid with responsive pagination and sidebar widgets.

== Gutenberg Block Patterns ==
Under the "AVR Web Consulting" category in the Block Editor (+):
- AVR Service Cards Grid
- AVR Hero Section
- AVR Comparison Table
- AVR FAQ Accordion
- AVR Free Audit CTA Banner

== Shortcodes ==
- [avr_phone]: Displays configured phone number
- [avr_email]: Displays configured company email
- [avr_whatsapp_url]: Displays direct WhatsApp chat link
- [avr_address]: Displays company office address
